# 智能体学习章节：实用可视化建议

本文件记录面向自学者的图形化呈现建议。图应把“信息从哪里来、什么被更新、如何验收”画清楚，而不把论文示意图当成通用结论。

## OPD

画一张双泳道时序图：上方是离线蒸馏的“教师轨迹 → 学生训练”，下方是 OPD 的“学生采样前缀 → 教师分布反馈 → 参数更新 → 新学生采样”。在学生前缀处标红一个早期错误，随后画出偏离的状态；在箭头旁标“更新权重”。交互版可用滑条调节 on-policy 数据比例，显示其只改变采样状态覆盖，不直接保证准确率。

## RSI

画带闸门的循环，而不是向上爆炸的箭头：目标与约束 → 候选改动 → 隔离实验 → 独立评测 → 通过／回滚 → 下一轮能力。每个候选改动用颜色区分“代码／数据配方／参数”和“提示词／记忆／工具流程”，使读者看到递归改进不必等于权重更新。可点击一个失败候选，展示预算耗尽、指标过拟合或安全检查拒绝如何中断循环。

## ACE

使用三栏图：左为执行轨迹和自然反馈，中为 Generator、Reflector、Curator 的增量处理，右为按主题折叠的 playbook。条目卡片固定显示“适用条件、策略、证据、版本”，并以灰色模型图标明确基础模型权重未变。交互时让用户比较“整段摘要反复重写”与“结构化增量合并”，观察后一种如何保留罕见条件；不要以动画暗示必然提升。

## Agentic RL

画 POMDP 回路：隐藏环境状态在背景，代理只接收观察；代理的动作经工具作用于环境，环境返回新观察与回报，整条 rollout 再交给优化器更新策略参数。另加一条虚线记忆通道，标为“上下文写入，不等于训练”。小型交互沙盒可让用户调节终局奖励、步骤成本与安全惩罚，观察奖励设计会引导不同策略，并保留“模拟环境可能被钻空子”的失败案例。
