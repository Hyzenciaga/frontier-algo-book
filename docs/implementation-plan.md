# 首版规划与后续路线

## 定位

一本可逐步扩写的中文自学手册。以学习依赖组织章节，以小实验解释机制，以一手论文限定主张。首版内容是概念入门，不是完整教材或真实训练基准。

## 已实现的第一阶段

- Docusaurus + React + TypeScript + MDX，纯静态输出。
- 学习路线、层级分类、前置依赖和过关标准。
- 15 篇主题章节，保留直觉、机制、例子、误区、自测、资料结构。
- 独立论文目录，首篇为 Transformer 原始论文的入门导读。
- DPO 标量损失、GRPO 组内优势、贪心投机解码三个可操作实验；仅嵌入对应知识章节。
- 响应式布局、系统字体、明暗主题、GitHub Pages 构建流程。
- 构建时断链检查、TypeScript 检查、数值性质测试。

## 框架决策

用户希望使用成熟 React 框架。选 Docusaurus 而不是裸 Vite，主要考虑书籍导航、静态深链接、MDX 内容维护；不需要 Next.js 服务端运行。首版无后端、登录或外部模型服务。依赖以 package-lock.json 固定；npm ci 复现。

## 第二阶段：补齐必要推导

1. 补充 tokenization、Transformer 推理与 KV cache 的图解，为推理加速打地基。
2. 增加策略梯度、baseline/GAE、PPO 裁剪与 KL 的详细推导。
3. 加入数学排版后统一符号，并标注原论文版本及公式出处。
4. 为自测问题补充折叠答案与可解释的反例。

## 第三阶段：真实复现

在独立实验目录中选择小模型与小数据：SFT → DPO → 可验证奖励训练。每次记录模型与数据版本、硬件、预算、训练曲线、独立评估和失败结果，不把教学交互的数值当作测量。

投机解码采用独立路线：随机接受和残差实验 → EAGLE / DFlash / DSpark 共同配置下的测量。比较单请求延迟与高并发吞吐，不能只报一个加速倍数。

## 扩写顺序

先完善基础与第二阶段算法推导，再深入 Agentic RL 与 OPD。ACE 作为上下文适应单独对待；RSI 以系统闭环与验证边界为主。`ego` 的真实名称待用户确认，当前 EAGLE 章节可独立保留。
