# SFT：先学会像示范那样回答

## 直觉

监督微调（Supervised Fine-Tuning，SFT）用“提示—理想回答”对，把预训练模型从续写互联网文本拉到遵循指令的起点。它通常是后续偏好优化的底座，而非“人类反馈强化学习”的同义词。InstructGPT 的流程先收集标注员示范并做 SFT，再收集多个模型回答的排序供后续阶段使用。

## 前置知识

模型把回答拆成 token，教师强制（teacher forcing）下每一步都以真实历史 token 为条件。损失是交叉熵的简化式：

```
L = - Σ_(x,y*) Σ_t log πθ(y*_t | x, y*_<t)
```

最小化它等于提高示范序列的条件概率。数据可来自人工撰写、专家流程、合成后审校或工具执行轨迹；来源不同，决定了“理想”的含义与偏差。训练时常从预训练模型开始，验证集要覆盖真实提示分布和安全边界。

## 流程

1. 定义任务与可接受行为，收集代表性提示。
2. 为每个提示准备可审查的目标回答，并清理冲突、隐私和低质量样本。
3. token 化、计算交叉熵、更新参数，保留验证集与基线。
4. 用人工评审、任务正确率、拒答质量等检查，而不是只看训练损失。

## 小例子

给定“把下列三点整理成表格”，示范答案包含 Markdown 表、没有杜撰条目。重复这类样本会让模型更常输出表格格式。但若所有示范都过度冗长，它也会学会冗长；SFT 会模仿数据分布，不会自动识别产品意图。

## 常见误区

“SFT 只需问答对”不准确：多轮上下文、系统约束、工具调用的输入与输出边界都必须编码进样本。也不要把单一标准答案当唯一真相；开放问题可有多个合格回答。SFT 也不是奖励模型：它直接拟合被选中的文本，不学习两个候选之间的相对偏好。

## 自测问题

1. 为什么 SFT 的训练损失下降不能单独证明更有帮助？
2. 一个工具调用轨迹中，哪些内容应作为模型目标 token？
3. SFT 数据的文风偏差会怎样传给后续 RL？
