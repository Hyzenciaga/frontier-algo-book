# Transformer：Attention Is All You Need

**Vaswani 等 · NIPS 2017 · 模型架构**

这是一份入门导读。先理解注意力计算，再沿原文章节深入；它不是完整 Transformer 复现。

## 直觉

读“猫没跳上桌子，因为它太累了”，理解“它”时，需要从上下文取回合适的信息。可以把注意力想成一次查资料：**Q 是查询，K 是索引，V 是索引背后的内容**。模型为不同位置打分，再按权重汇总内容。这是理解计算的比喻，不表示某个头一定学到了代词指代。

## 前置知识

先理解向量点积、矩阵乘法，以及将一组分数归一化成概率的 softmax。还不熟悉概率与生成时，可以先读[数学基础](../alignment/foundations.mdx)。

## 机制与公式

论文的 Transformer 使用编码器与解码器，用注意力连接序列位置，配合前馈网络、残差连接、归一化与位置编码。原始架构不是仅有一个 attention 层，也不是后来的 decoder-only 架构。

单头自注意力可拆成四步（`X` 为输入表示）：

```text
Q = X W_Q, K = X W_K, V = X W_V
S = Q Kᵀ / √d_k
A = softmax(S)            # 对每个 query 的一行做归一化
O = A V
```

若 `Q、K` 的形状为 `n × d_k`，`V` 为 `n × d_v`，则 `S、A` 是 `n × n`，输出是 `n × d_v`。多头使用不同的学习投影，分别计算后拼接，再投影。

### 为什么除以平方根？

在各分量独立、均值为 0、方差为 1 的简化假设下，`q·k` 的方差为 `d_k`，除以 `√d_k` 后方差为 1。这减轻大分数令 softmax 过于尖锐的问题；不是说真实训练中的向量严格满足该假设。

## 小例子与代码

下面是自编的两位置、单查询计算，只用 Python 标准库。它没有学习投影、多头或完整模型；两条 value 故意采用不同数值，便于观察加权结果。

```python
from math import exp, sqrt

q = [1.0, 0.0]
keys = [[1.0, 0.0], [0.0, 1.0]]
values = [[10.0, 0.0], [0.0, 20.0]]

scores = [sum(a * b for a, b in zip(q, k)) / sqrt(len(q))
          for k in keys]
# 减去最大值，提高 softmax 的数值稳定性。
weights = [exp(s - max(scores)) for s in scores]
weights = [w / sum(weights) for w in weights]
output = [sum(w * v[j] for w, v in zip(weights, values))
          for j in range(len(values[0]))]
print([round(w, 3) for w in weights])  # [0.67, 0.33]
print([round(x, 3) for x in output])   # [6.698, 6.605]
```

尝试将 `q` 改为 `[0.0, 1.0]`：查询改变后，权重会交换。再把两个 key 设为相同值，先预测权重，再运行检查。

## 常见误区

解码器的因果 mask 遮住未来位置。训练时可对已知的目标序列并行计算多个位置，但生成未知输出仍逐步进行；“训练可并行”不等于“一次生成全部答案”。这也是继续读[投机解码](../inference/speculative-decoding.mdx)的切入点。
