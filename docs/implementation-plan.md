# 手册规划与实现

## 定位与框架

以学习依赖组织中文算法教材，以公式和小程序解释机制，以原始资料限定主张。Docusaurus + React + TypeScript + MDX 提供章节目录、静态深链接与嵌入式实验；GitHub Pages 托管构建结果。依赖由 package-lock.json 固定。

## 已实现

- 15 篇主题章节：基础、SFT、RLHF、DPO、PPO、GRPO、RLVR、OPD、ACE、Agentic RL、RSI、投机解码、EAGLE、DFlash、DSpark。
- 学习路线与依赖表；章节保留原有结构，深入机制、公式、例子、代码、误区和自测。
- 论文目录与 Transformer 原始 encoder–decoder 导读。
- Benchmark 独立目录；首篇 τ-bench 从考察能力、任务样例、评分实现和可靠性指标展开。
- DPO、GRPO、投机解码和 pass@k / pass^k 四个交互实验，仅嵌入对应章节。
- 17 个标准库 Python 教学脚本，示例执行加入本地和 CI 检查。
- 本地打包的 KaTeX 数学排版、明暗主题、响应式布局。
- 类型检查、数值性质测试、静态构建断链检查、浏览器验收。

## 内容维护准则

正文使用正式作品语气，术语采用核验后的名称。区分算法、训练范式、系统闭环和工程建议，避免把教学假设写成论文要求。公式定义采样分布、符号和适用边界；代码注明简化环节与预期结果。引用原论文与官方代码，任务数据尽量固定版本。

Benchmark 章节统一关注考察能力、评分机制、数据集题型、具体任务表格和统计解释。区分 pass@k 的至少一次成功与 pass^k 的全部成功，说明独立试验、按题汇总及版本边界。

## 后续扩写

可以沿既有依赖增加 HumanEval、MMLU、GSM8K 等经典评测，以及与相应章节配对的论文导读。逐篇补充需要张量库的实现时，应同时保留可以手算的最小例子。

真实模型训练与性能复现另设实验：固定模型、数据、硬件和预算，记录独立评估与失败结果。SFT → DPO → 可验证奖励训练可构成一条实践路线；投机解码需同时比较单请求延迟和并发吞吐。教学脚本输出不作为真实模型成绩。
