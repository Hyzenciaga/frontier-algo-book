# 对齐训练的数学地基

## 直觉

语言模型首先是一个「下一个 token 概率分布」：给定前文 `x`，策略 `πθ(y|x)` 为每个可能的下一个 token `y` 分配概率。对齐训练不改变这个基本形式；它只是让分布更偏向人、规则或可验证器认可的完整回答。把一个完整回答看作连续动作，提示词是状态，模型便是一项序列决策策略。

## 前置知识

SFT 的训练样本是 `(x, y*)`，其中 `y*` 是目标 token。交叉熵（也就是负对数似然）可写成：

```
L_SFT = - Σ_t log πθ(y*_t | x, y*_<t)
```

它只奖励“把示范答案复现出来”。KL 散度衡量两个分布的差异，常用方向是 `KL(πθ || πref)`；它不是对称距离。对齐里 `πref` 往往是 SFT 后冻结的参考策略，用来限制模型为刷奖励而偏离语言能力。

强化学习的目标可简化为 `J(θ)=E[R]`。策略梯度的可采样形式是：

```
∇J ≈ Σ_t ∇log πθ(a_t|s_t) * A_t
```

`A_t`（优势）表示该动作比当前预期好多少；正值提高其概率，负值降低。它是简化式：实际实现还会有折扣、价值网络、归一化和 KL 正则。

## on-policy 与 off-policy

on-policy 指用于更新的数据由当前或刚刚冻结的策略采样；PPO 属于此类，数据过旧会使概率比和优势估计失真。off-policy 可以重用行为策略产生的旧数据，通常须做重要性校正或使用相应目标。DPO 常在固定偏好数据上直接训练，实务上通常称离线/离策略式偏好优化，但不应把“没有在线采样”误读为所有数学假设都消失。

## 小例子

提示“`2+2=?`”后，模型给 `4` 的概率从 0.7 提至 0.9 是一次策略改变。若奖励只看答案正确，模型可能开始输出极长推导来碰巧通过；加入相对参考模型的 KL，等于同时问它：提高奖励是否值得牺牲原本自然、稳定的分布？

## 常见误区

交叉熵小不等于人类更喜欢：它只拟合给定标签。KL 小也不等于安全：它只限制相对变化。策略梯度不是对奖励模型参数求导，而是利用采样回报调整生成概率。最后，token 概率高不代表整段答案的奖励高，序列回报可来自最终结果。

## 自测问题

1. 为什么 SFT 的目标不需要显式奖励函数？
2. `KL(πθ || πref)` 为什么能抑制奖励投机却不能保证正确？
3. 若样本来自很久以前的模型，为什么直接套 PPO 会有风险？
