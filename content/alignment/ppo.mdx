# PPO：限制每步策略改变的强化学习算法

## 直觉

PPO 允许用同一批 rollout 做多个小批更新，并用裁剪抑制一次更新把采样策略推得过远的激励。它是近端近似，不是硬 KL 约束的数学等价物。

## 前置知识与机制推导

旧策略 $\pi_{old}$ 采样 token 后，重要性比 $\rho_t=\pi_\theta(a_t|s_t)/\pi_{old}(a_t|s_t)$。clipped surrogate 为

$$
L^{clip}=\mathbb E[\min(\rho_tA_t,\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t)].
$$

正优势且比率超过 $1+\epsilon$ 时不再奖励继续抬升；负优势低于 $1-\epsilon$ 时也截断。实际语言 PPO 常加 value loss、熵项和对 reference 的 KL 惩罚。优势可由 $A_t=G_t-V(s_t)$ 或 GAE 估计；价值误差会把噪声带给策略。

## 数据流程

冻结行为策略，按 prompt rollout，保存每 token old log-prob、value、mask 与末端 RM/验证奖励；计算回报、归一化优势，再做有限 epoch minibatch。监控 clip fraction、近似 KL、熵、长度和 reward。rollout 过旧、epoch 太多或 token mask 错位都会使 ratio 无意义。

## GAE 与正负优势的分段手算

价值残差 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$，GAE 为 $A_t^{GAE}=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}$。$\lambda=0$ 只用一步 TD，方差低但依赖价值估计；$\lambda=1$ 接近 Monte Carlo，偏差小、方差高。例：两步终局，$V(s_0)=0.4,V(s_1)=0.6,r_0=0,r_1=1,\gamma=1,\lambda=0.95$，有 $\delta_0=0.2,\delta_1=0.4$，$A_0=0.2+0.95\times0.4=0.58$。

设 $\epsilon=0.2$。正优势 $A=2$ 时，$\rho=1.35$ 的未裁剪值为 $2.7$、裁剪值 $2.4$，取 $2.4$；该样本的 clipped surrogate 对继续提高 ratio 已无额外激励。负优势 $A=-2$ 时，同一 $\rho=1.35$ 的两个值是 $-2.7,-2.4$，取较小的 $-2.7$：提高坏动作概率仍会被惩罚；而 $\rho=0.7$ 时取 $\min(-1.4,-1.6)=-1.6$，避免把坏动作概率压得过低。这里的 old 是产生 rollout 的行为策略，用于重要性比；ref 是通常固定的 SFT 策略，用于语言能力锚定 KL，二者不能混用。

一个简化更新链路是：采样回复、RM 给末端奖励，价值网络给 $V$，用 GAE 产生每 token $A$，以 old log-prob 算 ratio，再加 reference KL。若没有保存 old log-prob，却拿 ref 替代，目标已不再是 PPO，对多 epoch 复用也失去近端含义。

## 小例子

```python
"""PPO clipped surrogate 在正、负优势下的逐样本目标。"""
def clip(x, lo, hi): return max(lo, min(x, hi))
for ratio, advantage in [(1.35, 2.0), (1.35, -2.0), (.7, 2.0)]:
    unclipped = ratio*advantage; clipped = clip(ratio,.8,1.2)*advantage
    print(ratio, advantage, "objective=", min(unclipped, clipped))
```

运行 `python examples/alignment/ppo.py`：正优势的 `1.35` 被截到 `2.4`，负优势不会被同方向误截。 [下载示例](../../examples/alignment/ppo.py)

## 常见误区

clip 不是保证 KL 小的锁；多轮更新仍可能漂移。优势归一化只改变尺度，不会修复错误奖励。奖励上升而人评下降是 RM 过优化的信号。

## 符号表与反向递推

$r_t$ 是环境或末端奖励，$\rho_t$ 是新旧策略概率比，$V_t$ 是价值估计，$\delta_t$ 是 TD 残差，$A_t$ 是优势。实现 GAE 常从末端反向：`gae = delta_t + gamma * lambda * nonterminal * gae`，再令 `return_t = gae + V_t`。终止 mask 很关键：漏乘会把下一条样本的价值泄入本题；把截断当终止则会系统性低估仍可继续的状态。

## 自测问题

1. 为何 ratio 用旧策略？
2. 正负优势的截断为何不同？
3. value 网络错会怎样？

<details>
<summary>答案</summary>

1. 它校正 rollout 的采样分布。
2. 目标对两种符号都取更保守项。
3. 优势方差或偏差增大，更新方向会变坏。

</details>
