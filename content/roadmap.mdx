# 学习路线：先理解问题，再学习算法

这本手册围绕一个问题展开：**大模型如何学习、如何在环境中改进，以及如何更快地生成？**

不必按缩写逐个背诵。先区分它们解决的问题，再沿前置知识学习。每章从直觉进入机制与公式，通过可运行代码检查理解，再回到原始论文。交互实验随知识点展开。

## 先认清四个层级

| 层级 | 你关心的问题 | 对应主题 |
| --- | --- | --- |
| 训练方法与优化算法 | 模型参数如何更新？ | SFT、DPO、PPO、GRPO、OPD |
| 反馈与奖励 | “好”的标准从哪里来？ | RLHF：人类反馈；RLVR：可验证奖励 |
| Agent 学习与系统改进 | 交互经验改变了什么？ | Agentic RL、ACE、RSI |
| 推理加速 | 怎样减少生成等待？ | 投机解码、EAGLE、DFlash、dSpark |

这些概念可以组合：例如用可验证奖励训练一个调用工具的 Agent，同时采用 GRPO 优化。**RLVR 不等于 GRPO，RLHF 也不等于 PPO。**

## 推荐阅读顺序

### 第一阶段：理解生成与监督学习

1. [基础：概率、损失与策略](./alignment/foundations.mdx)：token、自回归生成、交叉熵、KL、策略梯度。
2. [SFT](./alignment/sft.mdx)：如何从示范答案学习；明确数据、目标与泛化之间的关系。

**过关标准：** 能解释为什么 SFT 会提高示范答案的概率，却不保证答案正确。基础数学只需要概率、对数、导数和均值方差；不要求先完整学习强化学习教材。

### 第二阶段：偏好对齐与强化学习

1. [RLHF](./alignment/rlhf.mdx)：先认识反馈数据、奖励模型和策略优化的整体流程。
2. [DPO](./alignment/dpo.mdx)：从成对偏好直接学习，先建立“相对 reference 改变偏好”的直觉。
3. [PPO](./alignment/ppo.mdx)：补齐策略梯度、优势、重要性比和裁剪。
4. [GRPO](./alignment/grpo.mdx)：再理解用组内比较构造优势，以及省去价值模型的取舍。
5. [RLVR](./alignment/rlvr.mdx)：把奖励来源换成可检验的答案或测试，讨论验证器边界。

**过关标准：** 能分别回答“谁给奖励？”和“用什么算法更新？”。在 [DPO 章节](./alignment/dpo.mdx)中调节偏好参数，再到 [GRPO 章节](./alignment/grpo.mdx)把四个奖励设成相同值，解释为什么没有组内区分信号。实验跟随知识点阅读，无需跳转到独立实验页。

### 第三阶段：蒸馏、上下文与 Agent 学习

1. [OPD](./agents/opd.mdx)：理解学生自己生成的轨迹为何影响蒸馏。关注 On-Policy Distillation 中的采样分布与教师反馈。
2. [ACE](./agents/ace.mdx)：理解上下文如何积累经验；可以从 SFT 后直接阅读，不必先学 PPO。
3. [Agentic RL](./agents/agentic-rl.mdx)：将动作扩展到工具调用与多步交互，面对轨迹奖励和信用分配。
4. [RSI](./agents/rsi.mdx)：最后讨论递归自我改进的定义、评估和约束，避免将普通自训练等同于无限自进化。

**过关标准：** 面对一个“自进化系统”，能说清它改的是参数、上下文、代码、数据还是评估器，以及改进如何得到独立验证。

### 独立支线：推理加速

掌握 token、自回归生成与采样后，就可以学习[投机解码](./inference/speculative-decoding.mdx)，再阅读 [EAGLE](./inference/eagle.mdx)、[DFlash](./inference/dflash.mdx) 与 [dSpark](./inference/dspark.mdx)。这条支线**不要求先学 RLHF**。

**过关标准：** 能解释接受率、草稿成本和验证成本怎样共同决定加速；区分 greedy 演示和保持目标分布的随机投机采样。

## 依赖关系速查

以下是本书的教学依赖，并不表示历史发明顺序，也不表示实际系统必须使用这些组件。

| 主题 | 必须先理解 | 建议先读 |
| --- | --- | --- |
| SFT | 条件概率、交叉熵 | 基础 |
| DPO | SFT、成对偏好、reference | RLHF 总览 |
| PPO | 策略梯度、优势、概率比 | 基础、RLHF |
| GRPO | 优势、概率比、裁剪 | PPO |
| RLVR | 奖励与策略优化的区别 | GRPO；不限定优化器 |
| OPD | SFT、KL、采样分布 | 基础；不要求掌握 PPO |
| ACE | 上下文、工具与经验反馈 | SFT；不要求 RL |
| Agentic RL | MDP、轨迹、信用分配 | PPO / GRPO、RLVR |
| RSI | 训练与评估、反馈循环 | Agentic RL、ACE |
| 投机解码 | 自回归生成、概率采样 | 基础；不依赖对齐算法 |

## 术语说明与阅读方法

原始论文的阅读入口集中在[论文目录](/papers)。第一篇是 [Transformer：Attention Is All You Need](./papers/attention-is-all-you-need.mdx)，建议在基础概念之后阅读，为后续训练与推理章节补上架构直觉。

- **OPD（On-Policy Distillation）**：在学生采样的前缀上蒸馏教师分布。
- **ACE（Agentic Context Engineering）**：通过生成、反思和整理维护上下文。
- **EAGLE、DFlash、DSpark**：不同的投机草稿与验证策略，分别阅读其架构和假设。
- 每章先读直觉和例子，再检查机制、误区与自测，最后打开原始论文。公式注明教学简化，实验数值不代表真实模型测量。

## 把机制连接到评测

在 [Benchmark 目录](/benchmarks) 中，按“考察什么、怎样计分、任务长什么样”阅读评测。先读 [τ-bench](./benchmarks/tau-bench.mdx)，区分 pass@k 的至少一次成功与 pass^k 的每次成功，再思考 Agentic RL 的奖励是否真的覆盖了业务目标。
